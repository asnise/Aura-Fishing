## ช่วงที่ 1: วางโครงสร้างเกมและระบบหลัก (ไฟล์ `21_11_2026_01.txt`)

### [00:00 - 03:18] เปิดประชุม & Core Loop ของเกม
- **เนื้อหาที่คุย:** วางภาพรวม Game Design หลักของเกมตกปลา: ตกปลา -> ขายได้เงิน -> อัปเกรดเบ็ด/เหยื่อ/กระเป๋า -> ตกปลาที่แรร์ขึ้น -> นำไปโชว์ผู้เล่นอื่น
- **(เบสจากในเกม):** ระบบเศรษฐกิจหลักของเกมรองรับ 3 สกุลเงิน: Coins (เงินจากการขายปลา ใช้ซื้ออุปกรณ์, ตีบวก Enhance, ขยายช่องตู้ปลา), Gems (ได้จากการอัปเลเวล 5 Gems/Lv, ปลดล็อกปลาใหม่ 3 Gems, โบนัสปลาแรร์ หรือซื้อจาก Store ใช้สุ่ม Aura Altar 5 Gems/ครั้ง), Pearls (ผลิตจากตู้ปลา Aquarium แบบต่อวินาที +X/s สดทุกเฟรม ใช้อัปเกรด Mastery ถาวร 7 สาย)
- **สถานะ:** [สรุปแล้ว] เห็นตรงกันเรื่อง Core Loop หลัก

### [04:41 - 07:21] ระบบการตก, คันเบ็ด, สายเบ็ด และ Enchant
- **เนื้อหาที่คุย:** ทุกคนตกปลาได้เหมือนกันแต่ใช้เวลาต่างกัน แยกบทบาทอุปกรณ์: สายเบ็ดอัปเกรดได้ มีระบบ Enchant เพิ่มสแตท/Rarity ส่วนคันเบ็ดคุมการตกหลักและใส่ Mod/ความสามารถพิเศษ
- **(เบสจากในเกม):** คันเบ็ด (Rods) คุมระยะเหวี่ยง (CastRange), มินิเกม (CatchBarSize, ReelPower, Resilience), Luck, FishStability และ AutoSpeed ส่วนสายเบ็ด (Lines) ทำหน้าที่คุมเพดานความลึกสูงสุด (MaxDepth ตั้งแต่ 30m ถึง 1000m) และ Resilience โดยทั้งคันเบ็ดและสายเบ็ดมีระบบตีบวก Gear Enhance (+1 ถึง +10) ในตัวอยู่แล้ว ใช้ Coins เพิ่มสเตตัสระดับละ +4% ยกเว้น MaxDepth
- **สถานะ:** [ไอเดียใหม่] เสนอเพิ่มระบบสุ่ม Mod คันเบ็ดตอนซื้อ หรือเอาระบบย่อยคันเบ็ดซ้ำเพื่อตีบวก

### [10:56 - 11:53] จังหวะการสุ่ม (RNG Pacing)
- **เนื้อหาที่คุย:** ไม่อยากให้เกมต้องรอนานจนน่าเบื่อ อยากให้ผู้เล่นได้สุ่มเรื่อยๆ กะเกณฑ์ไว้ว่าเล่น 2 ชม. ควรได้สุ่มอย่างน้อย 10-20 ครั้ง (เฉลี่ย ชม. ละ 10 ครั้ง)
- **(เบสจากในเกม):** ปัจจุบันการสุ่มออร่าที่ Aura Altar ใช้ 5 Gems ต่อการสุ่ม 1 ครั้ง โดยผู้เล่นได้รับ Gems จากการเลเวลอัป, ปลดล็อกปลาสายพันธุ์ใหม่, ปลาแรร์, และเควสต์รายวัน
- **สถานะ:** [ยังไม่สรุป/คิดต่อ] ต้องนำตัวเลขการแจก Gems ไปคำนวณสมดุลต่อหลังประชุม

### [11:53 - 12:35] Character Progression, Mastery และ Aquarium
- **เนื้อหาที่คุย:** ระบบพัฒนาตัวละคร (Mastery / หน้าสกิล) โดยแต้มอัปเกรดจะได้จาก Aquarium บังคับให้ผู้เล่นนำปลามาใส่ Aquarium ด้วย ไม่ใช่แค่ตกมาขายอย่างเดียว
- **(เบสจากในเกม):** ตู้ปลา Aquarium ผลิต Pearls อัตโนมัติตามระดับ Rarity ของปลา (0.2 ถึง 40 ไข่มุก/นาที) x Mutation x PearlRate คำนวณและแสดงผลแบบต่อวินาที (+X/s) สดทุกเฟรม นำไปอัปเกรด Mastery ถาวร 7 สาย (ไม่หายเมื่อ Rebirth) ส่วนสกิลตัวละครใช้แต้ม Skill Point จากการเลเวลอัป (1 แต้ม/Lv) นำไปอัปสกิล Keen Eye, Quick Hands, Multi-Cast
- **สถานะ:** [สรุปแล้ว] โครงสร้างระบบ Aquarium และ Mastery สอดคล้องกับตัวเกมแล้ว

### [13:35 - 14:03] ระบบฟาร์มออฟไลน์ (AFK Cap)
- **เนื้อหาที่คุย:** ที่ประชุมเสนอเพดานเวลาฟาร์มออฟไลน์ไว้สูงสุดที่ 16 ชั่วโมง และสามารถเติมเงินขยายเพิ่มได้เป็น 20 ชั่วโมง
- **(เบสจากในเกม):** เพดานเวลาออฟไลน์พื้นฐาน (Base Offline Cap) ในโค้ดปัจจุบันอยู่ที่ 4 ชั่วโมง (`StatDefs.OfflineCapHours = 4`) หากซื้อ Gamepass VIP จะได้รับเพิ่ม +8 ชั่วโมง รวมเป็น 12 ชั่วโมง และสามารถอัปเกรดเพิ่มได้จาก Mastery สาย Offline Cap ได้อีกสูงสุด +8 ชั่วโมง รวมเพดานสูงสุดในเกมปัจจุบันอยู่ที่ 20 ชั่วโมง (ตัวเลข 16 ชม. ขยายเป็น 20 ชม. เป็นการเสนอปรับเพดานฐานใหม่)
- **สถานะ:** [ยังไม่สรุป/คิดต่อ] นำข้อเสนอปรับเพดานออฟไลน์ไปพิจารณาเปรียบเทียบกับระบบฐานเดิม

### [14:39 - 17:37] หน้าต่างตีบวก, หน้าตัวละคร และระบบเควส
- **เนื้อหาที่คุย:** พูดคุยเรื่องการจัดหน้าต่างตีบวก (Enhance), หน้าต่างตัวละคร และระบบเควส (Infinity Quest)
- **(เบสจากในเกม):** ในเกมมีระบบ Gear Enhance (+1 ถึง +10) ในการ์ดไอเท็มของร้านค้าและกระเป๋า, หน้าต่าง Character เป็นแบบ 2D Modal Cozy Lake, และมีระบบ Daily Quests (เควสต์รายวัน 3 เควสต์ แจก Gems)
- **สถานะ:** [ยังไม่สรุป/คิดต่อ] อยู่ระหว่างพัฒนาและปรับแต่งดีไซน์หน้าต่าง UI

- **สถานะ:** [สรุปแล้ว] เห็นชอบแนวทางแยกผลตอบแทนตกมือและออโต้

- **(เบสจากในเกม):** หน้าต่าง Character ในเกมปัจจุบันเป็น 2D UI สไตล์ Cozy Lake อยู่แล้ว ไม่ได้มีโมเดล 3D โฮโลแกรม

- **สถานะ:** [ไอเดียใหม่] ทีมเห็นชอบเป็นแนวคิดที่น่าสนใจสำหรับแผนอัปเดตระยะยาว
