Aura Fishing — โมเดลเศรษฐกิจ

จำลองการเล่น (ตกปลา → ขาย → ซื้อของ → เลเวล → สุ่มกาชา) นาทีต่อนาทีจากตัวเลข config ทุกช่องสีเทาด้านล่างแก้ได้ ผลคำนวณใหม่ทันที และจำค่าไว้ในเบราว์เซอร์นี้ ตัวเลขเป็นการประมาณ ต้องเทียบกับการเล่นจริงอีกที

เริ่มจาก:

สรุปสำคัญ

บรรทัดเล็กใต้ตัวเลข = ค่าเดียวกันของ preset "เกมตอนนี้" และ "แผน Pass 1" ไว้เทียบ

ไทม์ไลน์การเล่น

ผู้เล่นเล่น โดยเงินถูกใช้ซื้อของตามลำดับรายการ และ Gems ถูกใช้สุ่มกาชาทันทีที่พอ

จังหวะการซื้อของ

แถวสีส้ม = เงินพอแล้วแต่ต้องรอเลเวล (กำแพงเลเวล) — "ห่างจากชิ้นก่อน" คือช่วงที่ไม่มีอะไรให้ซื้อ

รายได้ต่อด่าน (ตามสายเบ็ด)

ผู้เล่นเลือกความลึกที่ได้เงินต่อตัวสูงสุดภายในเพดานสาย; Luck = คันที่ถืออยู่ตอนซื้อสาย + เหยื่อ + ออร่า

เลเวลและกาชา

จ่ายเงิน vs เวลาเล่น

ของแต่ละชิ้นเท่ากับเวลาเล่นกี่นาที ณ จุดอ้างอิง → ราคา Robux ต่อ 1 ชั่วโมงที่ผู้เล่นประหยัดได้ (ยิ่งต่ำ ยิ่งคุ้มในสายตาผู้เล่น)
