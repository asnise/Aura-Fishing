# Aura Fishing — Patch Notes (22–23 พฤศจิกายน 2026)

บันทึกการเปลี่ยนแปลงและอัปเดตระบบเกม Aura Fishing ระหว่างวันที่ 22 ถึง 23 พฤศจิกายน 2026 ครอบคลุมการยกเครื่องระบบไอเทม, ระบบ Mod อุปกรณ์, Rod Fusion, สารานุกรม Stats Codex, Daily Login ใหม่, การปรับปรุง UI บนมือถือ, การแก้ไขบั๊ก, และไปป์ไลน์ Aura VFX

---

## 1. ระบบใหม่ (New Systems & Features)

### C29 — Item Rework & UUID Bag (Save v6)
- **สถาปัตยกรรมไอเทมแบบ UUID**: เปลี่ยนโครงสร้างการเก็บข้อมูลไอเทมใน `profile.Bag` เป็นเรคคอร์ดอิสระที่มี UUID ประจำชิ้น
- **ปลา 1 ช่องต่อ 1 ตัว**: ยกเลิกการซ้อนปลา (non-stacking) แต่ละตัวมีน้ำหนัก, ค่า Mutation, Tags (Manual, Auto, Perfect, Hotspot) และราคาส่วนตัว
- **คันเบ็ดและสายเบ็ดในกระเป๋า**: ย้ายคันเบ็ดและสายเบ็ดมาอยู่ใน Bag ซื้อซ้ำได้, ขายคืนได้, สุ่ม Mod ได้ และ Enhance แยกรายชิ้น
- **บันไดความจุกระเป๋าใหม่**: ปรับขั้นความจุเป็น 10, 16, 24, 36 และ 50 ช่อง
- **Save Profile v6**: อัปเกรดเวอร์ชันเซฟเพื่อรองรับโครงสร้างกระเป๋าใหม่ ล้างข้อมูลไอเทมรูปแบบเก่าอัตโนมัติ

### C30 & C34 — ระบบ Modifier คันเบ็ดและสายเบ็ด (Prefix / Suffix)
- **สุ่ม Mod อุปกรณ์**: คันเบ็ดและสายเบ็ดระดับ Uncommon ขึ้นไป มีโอกาสสุ่มได้รับทั้ง Prefix และ Suffix
- **สเตตัสบวกและลบ (-N ถึง +N)**: สุ่มค่าสเตตัสที่ช่วยเพิ่มหรือลดความสามารถ โดยค่าติดลบจะแสดงชิปสีแดงบนการ์ดไอเทม
- **Cap Breaker Mod**: เพิ่ม Mod พิเศษที่ขยายเพดานสเตตัสสูงสุดเดิมของเกม เช่น `MaxCatchBarSize` (ขยายเพดานจาก 60% ได้สูงสุด 75%), `MaxAutoSpeed` และ `MaxResilience`
- **ระบบดรอปอุปกรณ์**: เชื่อมโยงโอกาสได้รับคันเบ็ดพร้อม Mod จากการตกปลา (ในจุดน้ำลึกและจุดฟอง Hotspot) และการเปิดหีบสมบัติ

### C31 — ระบบ Rod Fusion (หลอมย้าย Mod เบ็ด)
- **เปิดใช้งานที่ NPC Old Marlin**: ระบบหลอมรวม 4 ขั้นตอน (Base, Material, Type, Compare)
- **ย้าย Mod ข้ามคันเบ็ด**: สามารถเลือกโอนย้าย Mod 1 บรรทัดจากคัน Material ไปยังช่องของคัน Base ชนิดเดียวกัน โดยคัน Material จะสลายตัวเสมอ
- **อัตราความสำเร็จและการการันตี**: มีโอกาสล้มเหลว 5% และมีระบบ Guard ด้วย Gems เพื่อการันตีสำเร็จ 100%
- **ระบบตรวจระยะ**: เซิร์ฟเวอร์ตรวจสอบระยะห่างระหว่างผู้เล่นกับ Old Marlin ป้องกันการสั่งหลอมข้ามแมพ

### C35 — Stats Codex (สารานุกรมสเตตัส)
- **เข้าถึงได้จาก Main Menu**: หน้าต่างสารานุกรมรวม 86 รายการ ครอบคลุม 16 Stats, 5 Cap Breakers, 38 Rod Mods, 4 Mutations และ 23 Item Attributes
- **Searchable Index**: ระบบค้นหาแบบเรียลไทม์ พร้อมตัวกรองแยกแท็บ All, Stats, Rod Mods และ Attributes
- **ไอคอนทางการ**: อัปโหลดไอคอน `ui/icons/statscodex` (Roblox Asset ID: `122180566876353`)

### C23 — Daily Login แบบ B "Grand Shelf"
- **นำดีไซน์ B ลงเกมจริง**: ใช้เลย์เอาต์ Grand Shelf พร้อมการ์ดสไตล์ปฏิทิน 7 วัน และอบ (Bake) ลง StarterGui
- **สถานะ Claimed ชัดเจน**: วันที่รับรางวัลแล้วจะแสดงเลเยอร์สีมิ้นต์โปร่งพร้อมตราประทับ CLAIMED
- **ทางลัดบน HUD และ Main Menu**:
  - เพิ่มปุ่ม `BtnDaily` บน HUD (มุมซ้ายใต้แถบ Stats) แสดงเฉพาะวันที่ยังไม่ได้กดรับ พร้อมจุดแจ้งเตือนสีแดง (รับแล้วซ่อนตัวเอง)
  - เพิ่ม Tile Daily ใน Main Menu พร้อมจุดแจ้งเตือนสีแดง
  - นำการ์ด Daily ออกจากหน้าต่าง Events

## 2. ปรับปรุง UI และการรองรับมือถือ (UI & Responsiveness)

### C34 — หน้าร้านค้า (Store Pagination & Pass List)
- **ยกเลิก Scroller บนจอสั้น**: หน้าต่างร้านค้าบนจอมือถือเปลี่ยนมาใช้ปุ่มลูกศร `<` และ `>` เพื่อสลับหน้า (Paginate) แทนการเลื่อน
- **รายการ Gamepasses แถวสูง 88**: ปรับการแสดงผลบัตรผ่านเป็นรายการแนวนอน อ่านง่าย ปุ่ม Action ชิดขวาตามแบบ Figma C6b

### C34 — การ์ดแสดงรายละเอียดไอเทม (Item Detail Card)
- **การ์ดย่อขนาดตามหน้าจอ**: ยกเลิกการเลื่อนข้อความภายในการ์ด โดยใช้การย่อสเกลรวม (ไม่ต่ำกว่า 0.5) และซ่อนคำอธิบายที่ไม่จำเป็นบนจอขนาดเล็ก
- **แก้ไขกรอบรูปภาพ**: ปรับ Body ของการ์ดเป็น Frame ปกติ แก้ไขปัญหามุมช่องรูปถูกตัด

### C34 — หน้าต่างตีบวก (Enhance Popup)
- **เลย์เอาต์ 2 คอลัมน์บนมือถือ**: แสดงไอเทมฝั่งซ้าย และตารางสเตตัสฝั่งขวา พร้อมแถบแจ้งเตือนการเลื่อนเมื่อมีแถวสเตตัสเกิน 4 แถว

### C34 — พื้นหลังเมนูเต็มจอ (MenuBackdrop)
- **ครอบคลุมเต็มจอไร้ขอบ**: ปรับ `MenuManager` ให้แสดงพื้นหลังสีดำโปร่งครอบคลุมทั้งหน้าจอโดยไม่ติดขอบ Safe Area เมื่อเปิดหน้าต่างเมนูหลัก

### C32 — ความสะดวกในกระเป๋า (Inventory UX)
- **จัดเรียงเริ่มต้นเป็น Newest**: ไอเทมที่เพิ่งได้รับจะแสดงอยู่ด้านบนสุดเสมอ
- **ปุ่ม NEW n**: ปุ่มลอยนำทางไปยังไอเทมใหม่ชิ้นแรกในกระเป๋า
- **Clean Interface**: ถอดแถบ Highlights, ป้าย TOP/UP และขอบเรืองความหายากออกจากช่องไอเทม

### C33 — ตรวจสอบและ Bake UI ครบ 18 หน้า
- **Bake ลง StarterGui**: อัปเดตและบันทึกหน้าต่างทั้งหมด 18 หน้าลงในเพลส
- **ปรับระยะขอบ**: ปรับขนาดกรอบ Upgrade Bag และเว้นระยะขอบป้ายสถานะการตกปลา (`Auto fishing...`, `Waiting...`) บนหน้าจอมือถือ

## 3. ปรับสมดุลและการแก้ไขบั๊ก (Fixes & Balance)

- **แก้ไขบั๊กหน้าจอดำค้าง**: แก้ไขจุดที่ `GachaPageController` ถูกเรียกซ้ำซ้อนจนสร้างหน้าต่างทับกัน และปรับให้ `MenuManager` ตรวจเช็กสถานะพื้นหลังดำอัตโนมัติ
- **แก้ไขหน้าต่างเด้งขยายใหญ่**: ปรับระบบ `FitToScreen` ให้คำนวณขนาดหน้าต่างให้พอดีจอก่อนแสดงผลในเฟรมแรก
- **ปรับกติกาอุปกรณ์เริ่มต้น**: คันเบ็ด Driftwood Rod และสาย Cotton Line ขายคืนได้ 0 Coins และจำกัดให้เป็นเจ้าของได้ชนิดละ 1 ชิ้นในร้านค้า
- **ราคาขายคืนอุปกรณ์**: อุปกรณ์ที่มี Mod หรือผ่านการตีบวกจะได้รับมูลค่าขายคืนเพิ่ม 40% จากราคาอุปกรณ์และเงินที่ใช้ตีบวก
- **ปุ่มปิดหน้า Gacha**: เปลี่ยนปุ่มย้อนกลับ `<` ของหน้า Gacha Summon เป็นปุ่มกากบาท `X` สีแดงมาตรฐาน

## 4. งานกราฟิกและเครื่องมือพัฒนา (Art Pipeline & Tools)

### C36–C38 — ไปป์ไลน์ Aura VFX ครบ 15 ออร่า
- **สเปกและพรอมป์ 75 ชีต**: จัดทำเอกสารข้อกำหนด พรอมป์ AI Image Gen (5 เลเยอร์ต่อออร่า) และไฟล์กำกับพารามิเตอร์ Particle ครบทั้ง 15 ออร่า
- **Texture ชีตชุดแรก**: สร้างชีต Texture ขนาดเต็มสำหรับ 3 ออร่านำร่อง (`TidalBloom`, `MoonlitRipple`, `NebulaKoi`)
- **เว็บพรีวิว HTML5 Canvas**: สร้างหน้าพรีวิวจำลองแอนิเมชันและการแสดงผล 3 ระดับ (Tier 1-3) บนเบราว์เซอร์

### C39 — Aura Particle Editor & Importer
- **Aura Particle Editor**: เครื่องมือปรับแต่ง JSON อนุภาคและพรีวิวบน Windows
- **Studio Importer Plugin**: ปลั๊กอินบน Roblox Studio สำหรับนำเข้าโมเดลและผูก Asset ID เข้าสู่ `ReplicatedStorage.AuraVFX`

### คลัง Assets ใน Roblox Studio
- **ReplicatedStorage.Assets**: จัดระเบียบโฟลเดอร์เก็บข้อมูล Assets ในเกมรวม 208 รายการ (Icons, Items, Auras, Fish, UI, NPC) พร้อม Decal พรีวิวและ Attributes

### Aura Fishing QA Web
- **ระบบเว็บตรวจงาน (GitHub Pages + Firestore)**: เปิดใช้งานเว็บตรวจงาน QA รองรับการบันทึกสถานะงาน 80 รายการ, ระบบเกม 23 ระบบ, และฟอรัมข้อเสนอแนะ/แจ้ง Ticket
