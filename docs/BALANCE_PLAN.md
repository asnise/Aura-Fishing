# Aura Fishing — แผน Economy & Balance (ร่าง 2026-11-17)

> เป้าหมาย (ผู้ใช้กำหนด): **แจกหนัก ได้เงินง่าย — โดปามีนมาจากการ "ได้ใช้จ่าย / ซื้อ / ขาย" บ่อย ๆ** แต่ระบบต้องไม่พัง
> เล่นสบาย ๆ เห็น Progression ตลอดเวลา, content ไม่โดนรีดหมดเร็ว, มีระบบ idle ที่ตัวเลขขึ้นตลอดแล้วเอาไปทำให้ตัวละครเก่งขึ้นจริง
> ตัวเลขทั้งหมดในไฟล์นี้ = ค่าตั้งต้นสำหรับ tune (คำนวณด้วย sim, ยังไม่ได้วัดในเกมจริง)

---

## 1. กติกาที่ทำให้ "แจกหนักแต่ไม่พัง"

1. **รายได้โตแบบเส้นตรง, ราคาโตแบบทวีคูณ** — ได้เงินเยอะขึ้นเรื่อย ๆ แต่ของชิ้นต่อไปก็แพงขึ้นเร็วกว่า เลยมีเป้าหมายถัดไปเสมอ
2. **ทุกที่ใช้เงินต้อง "ไม่มีก้น"** — นอกจากของชิ้นเดียวจบ (คัน/สาย/กระเป๋า) ต้องมีที่ใช้เงินแบบอัปได้เรื่อย ๆ: Gear Enhance, ขยายบ่อปลา, เหยื่อ (ของสิ้นเปลือง)
3. **ความเก่งถูกกั้นด้วยเลเวล/โซน ไม่ใช่เงินอย่างเดียว** — เงินล้นได้ แต่ข้ามขั้นไม่ได้
4. **ตัวคูณซ้อนกันต้องมีเพดาน** — Luck ใช้ diminishing returns, stat มี Max ใน `StatDefs`
5. **Rebirth รีเซ็ตเงิน** — โดปามีนการซื้อกลับมาใหม่ทุกรอบ พร้อมตัวคูณถาวร
6. **ตัวเลขใหญ่ = รู้สึกดี** — คูณมูลค่า/ราคาทั้งหมด ×10 (เกมแนว Simulator), ขายแล้วตัวเลขวิ่งขึ้น (count-up)

## 3. ขาย = โดปามีน (Trading กับ NPC)
- **Sell All แบบตัวเลขวิ่ง** + เสียง/คอนเฟตตีตามยอด (UI)
- **"ปลาขายดีประจำชั่วโมง" ที่ Merchant**: สุ่ม 1–2 ชนิด ราคา ×2–×3 หมุนทุก 60 นาที (ทั้งเซิร์ฟเวอร์เหมือนกัน) → เกิดการตัดสินใจ "เก็บไว้รอขาย / ขายเลย / ใส่บ่อ"
- **ไม่ทำเทรดระหว่างผู้เล่นตอนนี้** (เสี่ยงโกง/scam/dupe และต้องทำระบบกันเยอะ) — ค่อยพิจารณาหลังเปิดเกม

## 4. ระบบ idle: บ่อปลา (Aquarium) → 🫧 Pearls → Mastery
- ปลาที่ตกได้: **ขาย** หรือ **ใส่บ่อ** → ปลาในบ่อผลิต Pearls ตลอด (ออฟไลน์ได้ สูงสุด 4 ชม. อัปได้)
- อัตรา Pearls/นาที: Common 0.2 · Uncommon 0.5 · Rare 1.5 · Epic 4 · Legendary 12 · Mythic 40 × ตัวคูณ mutation
- ช่องบ่อ: เริ่ม 3 ช่อง, ขยายด้วย Coins (5k → 20k → 80k → 300k → 1M … ×~3.5)
- **Mastery** (ใช้ Pearls, อัปได้ไม่มีเพดาน, ราคา ×1.15/เลเวล): Luck · Catch Bar · Reel Power · Auto Wait · Pearl Rate · เพดานออฟไลน์ · Sell Mult
- กลับเข้าเกม: popup "ระหว่างคุณไม่อยู่ +X 🫧"

### Gear Enhance (ที่ใช้ Coins แบบไม่มีก้น)
- คัน/สายที่มีอยู่ อัป +1…+10 ได้ ราคา = 10% ของราคาของ × 1.5^เลเวล, แต่ละขั้น stat หลัก +4%

## 5. Gacha — สุ่มได้ถี่ ทุกครั้งมีค่า
- รายได้ Gems เป้าหมาย: **~15 สุ่ม/ชม. ช่วงแรก**, ~8–10/ชม. ช่วงหลัง (ปลา Rare+, เลเวลอัป, หีบ, จับชนิดใหม่ครั้งแรก +3, เควสต์รายวัน, milestone)
- ออร่าซ้ำ → **ดาว ★1–★5** (แต่ละดาว stat +20%)
- Pity: **Legendary ทุก 100**, **Mythic ที่ 300**; x10 การันตี **Rare+**
- แสดงอัตราจริงให้ถูก (Sparkling Dew ตอนนี้แสดง 1/10 แต่ออกจริง ~99%)
- เพิ่มออร่า/แบนเนอร์ใหม่ทุก ~2 สัปดาห์ (ต้องขออาร์ต)

## 7. ออกแบบให้ "ติด" (Retention) — ทำงานยังไง

### 7.1 วงจร 3 ระดับเวลา (ทุกระดับต้องจบด้วย "ได้ของ / เห็นตัวเลขขึ้น")
| ระดับ | วงจร | จุดโดปามีน |
|---|---|---|
| **วินาที** (ทุกตัวที่ตก) | ! → มินิเกม → เปิดเผยปลา | ปลาลับ `???` เฉลยตอนจับได้, mutation, NEW!, หีบสมบัติ, Hot Streak นับขึ้น |
| **นาที** (session) | กระเป๋าเต็ม → **ขายรวด** → **ซื้อของ** → ลงลึกขึ้น → สุ่มกาชา | ตัวเลขขายวิ่ง, ปุ่มซื้อเปลี่ยนเป็นสีเขียวเมื่อเงินพอ, ออร่าใหม่/ดาวเพิ่ม |
| **วัน/สัปดาห์** | เข้าเกม → เก็บ Pearls ออฟไลน์ → เควสต์รายวัน → ปลาขายดีประจำชั่วโมง → อีเวนต์แบนเนอร์ | popup "+X 🫧 ระหว่างไม่อยู่", login streak, milestone อีเวนต์ |

### 7.2 กลไกทางจิตวิทยาที่ใช้ (แบบไม่เป็นพิษ)
- **เป้าหมายถัดไปเห็นตลอด (Goal gradient):** HUD แสดง "ของชิ้นต่อไป: Coral Rod 72%" — ใกล้เต็มยิ่งอยากเล่นต่อ
- **รางวัลแบบสุ่ม (Variable reward):** mutation, หีบ, ปลาหายาก, กาชา — แต่มี pity/ดาว กันดวงซวยจนเลิกเล่น
- **สะสมให้ครบ (Collection):** Fishdex มีรางวัลทุก 25/50/75/100% + ชนิดใหม่ครั้งแรก +3 Gems
- **ความคืบหน้าที่ไม่หาย:** Mastery, ดาวออร่า, Fishdex ไม่ถูก Rebirth ล้าง → รู้สึกว่าเวลาที่เล่นไม่สูญเปล่า
- **โชว์ให้คนอื่นเห็น:** ประกาศทั้งเซิร์ฟเมื่อได้ Legendary+, ออร่ารอบตัว, ฉายาเหนือหัว, Leaderboard
- **ทำร่วมกัน:** บอสพญานาค co-op (C5) — เหตุผลให้ชวนเพื่อน

### 7.3 "ความไม่สะดวก" ที่แก้ได้เรื่อย ๆ (และขายได้)
หลัก: **ทุกความไม่สะดวกต้องมีทางแก้ฟรีด้วยการเล่น** — ของ Robux = ทางลัด/สะดวกขึ้น ไม่ใช่ทางเดียว
| ความไม่สะดวก | ทางแก้ฟรี (Progression) | ทางลัดขาย (C6) |
|---|---|---|
| กระเป๋าเต็มบ่อย | ซื้อกระเป๋าใหญ่ขึ้น | Infinite Bag |
| ต้องเดินไปขายที่ร้าน | Mastery "Remote Sell" (ปลดที่ Lv.X) | ขายได้ทุกที่ + Auto-Sell |
| Auto หยุดเมื่อกระเป๋าเต็ม | Auto-Sell ปลา Common (Mastery) | Auto-Fish Pro |
| Auto ช้า | AutoSpeed จากคัน/เหยื่อ/Mastery | Auto-Fish Pro (-25% Auto Wait) |
| Pearls ออฟไลน์เต็มเพดาน | Mastery เพดานออฟไลน์ | VIP (+เพดาน) |
| ต้องซื้อเหยื่อบ่อย | Mastery Auto-Rebuy | แพ็กเหยื่อ |
| สายเดียว | สกิล Multi-Cast (C4) | Extra Cast |

### 7.4 เส้นที่ไม่ข้าม (ผู้เล่นอายุ 9–24 + กฎ Roblox)
- ของสุ่มที่จ่าย Robux ได้ (ทางตรงหรือทางอ้อม) **ต้องแสดงอัตราจริง** ก่อนจ่าย
- ไม่มีตัวจับเวลาที่ทำให้กังวล/ลงโทษเมื่อไม่ได้เข้าเกม (login streak พลาดแล้วไม่หายทั้งหมด)
- ไม่ขาย power ที่ผู้เล่นฟรีหาไม่ได้เลย; ไม่ใช้ป๊อปอัปเร่งซื้อแบบหลอก

## 8. ข้อสรุปหลังเทียบกับเอกสาร agent (2026-11-17)
อ้างอิง `docs/aura_fishing_economy_monetization_model.md` + ผลจากหน้าโมเดล `docs/economy/economy-model.html`
- **รายได้เงิน:** ใช้แบบแจกหนักของแผนนี้ (ซื้อของทุก 1–3 นาทีช่วงแรก) — ไม่ใช้ 3–5k coins/ชม. ของเอกสาร agent; ใช้สัดส่วนราคาช่วงท้ายของเขาได้
- **กาชา:** เป้า ~10–15 ครั้ง/ชม. (กลางระหว่าง agent 3–5 กับโมเดลแผนนี้ 19–31)
- **ช่วง 2–12 ชม. ไม่มีของให้ซื้อ + กำแพงเลเวล Naga Rod ~8 ชม.** (จากโมเดล) → Gear Enhance (C16) + บ่อปลา (C14) มาเติม และลด XP เพิ่มใน C12
- **ใช้จากเอกสาร agent:** ราคา pass (Infinite Bag 499, Auto-Fish Pro 399, VIP 199), VIP ขยายออฟไลน์ 12 ชม., Star Token จากออร่าซ้ำ, Gem bundles 40/160/400, Boost 2x Coins/Pearls 2 ชม., วัตถุดิบโซนลึกสำหรับตีบวกขั้นสูง (เฟส 2)
- **ไม่ใช้จากเอกสาร agent:** Auto-Fish Pro ทำให้ Auto เท่าเล่นมือ 100% (ใช้ −25% Auto Wait + ×1.25 แทน); Starter Pack ที่ให้ Coral Rod + กระเป๋า 15 ช่อง (ข้ามช่วงซื้อของที่สนุกที่สุด → ให้ Gems + เหยื่อ + คันพิเศษ stat เบาแทน)
- งานที่เกิดขึ้น: C12–C19 ใน `docs/TASKS.md`
