# Aura Fishing — Gacha Art Generation Prompts Pack (Pure Aura VFX Edition)

คู่มือรวม Prompt สำหรับนำไปสร้างภาพประกอบ (Image Generation) ทั้ง Aura Splash Art, Background แบนเนอร์, และ Banner Tabs สำหรับหน้าจอ Gacha ใหม่ของเกม Aura Fishing

ข้อกำหนดสำคัญที่สุดของเกม Aura Fishing:
- เกมนี้สุ่มและขายเฉพาะ "Aura Visual Effects" (พลังเวทมนตร์, วงแหวนธาตุ, พายุพลังงาน, ละอองแสง, และดวงจิตสัตว์เทพที่วนรอบตัวผู้เล่นและคันเบ็ด)
- ห้ามมีตัวละครมนุษย์, หน้าคนอนิเมะ, หรือคอสเพลย์โดยเด็ดขาด (No humans, no anime characters, no human figures, no faces)
- ภาพ Aura เด่นต้องเป็นไฟล์ PNG พื้นหลังโปร่งใส (Transparent Background) เพื่อนำไปวางบนหน้าต่าง Gacha ได้แนบเนียน

แนะนำให้ใช้สร้างผ่าน Midjourney v6, Niji 6, DALL-E 3 หรือ Stable Diffusion XL
