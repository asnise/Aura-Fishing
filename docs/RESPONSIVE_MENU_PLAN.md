# แผนปรับปรุง Responsive เมนู และระบบแสดงความโดดเด่นของ Item Card ใน Scroller

แผนแม่บทสำหรับปรับปรุง UI เมนูทั้งเกม Aura Fishing ครอบคลุมการแสดงผลทุกขนาดหน้าจอ (Responsive Viewports), การจัดสัดส่วน Safe Area และการแก้ปัญหา UX สำคัญ: **"ผู้เล่นได้รับไอเทมแต่ไม่รู้ว่าของตัวเองน่าสนใจแค่ไหนเพราะถูกกลืนไปใน Scroller"**

---

## 1. วัตถุประสงค์หลัก (Core Objectives)

1. **Item Discovery & Notability:** เมื่อผู้เล่นได้รับไอเทมใหม่ (ปลาหายาก, เบ็ดติด Modifier เทพ, การกลายพันธุ์ Mutation หายาก หรือไอเทมที่มี Stat สูงกว่าของเดิม) ผู้เล่นต้องรับรู้ได้ทันทีตั้งแต่เปิดเมนู โดยไม่ต้องไถเลื่อนหาเองในรายการยาว
2. **In-Slot Visual Telegraphing:** ตัวสล็อตไอเทม (`ItemSlot`) ใน `VirtualGrid` ต้องสื่อสารความพิเศษได้ชัดเจนผ่านสี Rarity, ป้ายสถานะ (God Roll / Upgrade / Hot / New) และเอฟเฟกต์กรอบ
3. **Seamless Mobile Responsive:** ทุกหน้าต่างเมนูและป๊อปอัปรายละเอียด (`ItemDetail`) ต้องแสดงผลสมบูรณ์บนทุกขนาดหน้าจอ (คอมพิวเตอร์, แท็บเล็ต, มือถือแนวนอน และมือถือแนวตั้ง) ไม่ตกขอบ ไม่ซ้อนทับ และปุ่มสำคัญ (ปิด/ยืนยัน) ต้องกดได้เสมอ

---

## 2. โครงสร้างสถาปัตยกรรม UI ที่เกี่ยวข้อง (Component Breakdown)

ระบบแสดงผลเมนูและรายการไอเทมในเกมขับเคลื่อนด้วย 5 องค์ประกอบหลักที่ต้องเตรียมการและเชื่อมโยงกัน:

### 2.1 Window Shell & Adaptive Scaling
- **ไฟล์หลัก:** `src/client/UI/Window.luau`, `src/client/UI/New.luau`
- **หน้าที่:** สร้างกรอบหน้าต่างหลัก (`Window.Shell`), จัดการขอบโค้ง (`RadiusWindow`), ฟังก์ชันย่อ-ขยายอัตโนมัติตามขนาดจอ (`New.FitToScreen`), และแผงตัดขอบโค้ง (`CanvasGroup` เมื่อใช้ `Clip = true`)
- **จุดที่ต้องเตรียม:**
  - การรองรับ `GuiService:GetGuiInset()` สำหรับ Safe Area บนมือถือที่มีรอยบาก (Notch)
  - การจำกัดขนาดสูงสุด (Max Height/Width) บนจอเตี้ย (ความสูง < 600px) เพื่อไม่ให้ส่วนหัวหรือท้ายหน้าต่างหลุดออกนอกจอ

### 2.2 Scroller & Virtualization Core
- **ไฟล์หลัก:** `src/client/UI/VirtualGrid.luau`, `src/client/UI/Screens/Inventory.luau`
- **หน้าที่:** จัดการแสดงผลสล็อตไอเทมจำนวนมาก (50-500 ช่อง) โดยสร้างและ Reuse มุมมองเฉพาะแถวที่มองเห็นในหน้าจอ บวกระยะ Buffer ช่วยให้เปิดกระเป๋าใหญ่ได้ลื่นไหล ไม่กระตุก
- **จุดที่ต้องเตรียม:**
  - เพิ่มฟังก์ชัน `grid:ScrollToItem(predicate)` หรือ `grid:ScrollToIndex(i)` เพื่อให้สามารถสั่งเลื่อนหน้าจอไปยังไอเทมเป้าหมายได้ทันที
  - เพิ่ม Event / Hook แจ้งเตือนเมื่อไอเทมเป้าหมายเลื่อนเข้ามาอยู่ในมุมมอง (Visible Viewport)

### 2.3 Item Slot Representation
- **ไฟล์หลัก:** `src/client/UI/ItemSlots.luau`, `src/client/UI/Screens/Components.luau`
- **หน้าที่:** สร้างและผูกข้อมูล (`Bind`) ให้กับสล็อต 72px (`ItemSlot`)
- **เลเยอร์ที่มีอยู่เดิม:**
  - มุมสี Rarity (`CornerColor`)
  - วงแหวนของที่สวมใส่อยู่ (`Ring = T.SkyLip`)
  - ป้าย Enhance (`PlusBadge = +N`)
  - ป้ายราคาพิเศษ (`Hot = xN`)
  - ป้ายไอเทมใหม่ (`New = true`)
  - ไอคอน Mutation ปลา (`Mutation = fish/mut_*`)
- **ส่วนที่ต้องขยายเพิ่ม:**
  - ป้าย "GOD ROLL" หรือ "TOP TIER" สำหรับอุปกรณ์ที่มี Stat สุ่มได้ค่าสูงสุด
  - ป้าย "UPGRADE" (ลูกศรเขียว) เมื่อไอเทมในกระเป๋ามี Stat ดีกว่าของที่สวมใส่อยู่ปัจจุบัน
  - เส้นขอบเรืองแสงสำหรับ Rarity ระดับสูง (Legendary, Mythic, Secret)

### 2.4 Item Card Popover & Details
- **ไฟล์หลัก:** `src/client/UI/ItemDetail.luau`, `src/client/UI/Screens/ItemDetail.luau`
- **หน้าที่:** แสดงข้อมูลแบบเจาะลึก (ชื่อ, Rarity, ค่า Stat, Modifier Prefix/Suffix, คำอธิบาย, ปุ่มคำสั่ง Equip / Sell / Enhance / Star Up)
- **จุดที่ต้องเตรียมสำหรับ Responsive:**
  - **บนจอคอมและแท็บเล็ต:** วางการ์ดด้านข้างสล็อตที่แตะ (`Side-by-side`) พร้อมเข็มชี้ (`Nub`)
  - **บนจอมือถือ (พื้นที่ด้านข้างไม่พอ):** สลับโหมดเป็น Bottom-Sheet หรือ Center Modal อัตโนมัติ เพื่อไม่ให้การ์ดหลุดขอบจอและไม่บังพื้นที่กดยืนยัน

### 2.5 Menu Navigation & State Manager
- **ไฟล์หลัก:** `src/client/UI/MenuManager.luau`
- **หน้าที่:** ควบคุมการเปิด-ปิดหน้าต่าง การจัดเลเยอร์ (Hub, Main, Dialogue, Popup, Modal) และการปิดหน้าต่างด้วยปุ่ม Escape / ปุ่มปิด

## 3. แผนแก้ปัญหา Item Card ใน Scroller (Item Discovery & Notability Framework)

### 3.1 ปัญหาปัจจุบันที่ต้องแก้ไข
1. **The Buried Item Problem:** ผู้เล่นตกปลาได้ระดับ Mythic หรือเปิดกล่องได้เบ็ดใหม่ แต่เมื่อเปิดกระเป๋า ไอเทมกลับไปอยู่ท้ายแถวหรือปนอยู่กับขยะ ผู้เล่นไม่รู้ว่าของที่ได้มามีคุณค่าอย่างไรหากไม่เลื่อนหาทีละแถว
2. **Low Visual Distinction:** สล็อตใน Grid มีขนาด 72px ข้อมูลบนหน้าการ์ดยังขาดตัวบ่งชี้ความพิเศษเชิงลึก (เช่น อุปกรณ์ชิ้นนี้ตีบวกคุ้มไหม, ค่า Stat ดีกว่าของเดิมหรือไม่, มี Modifier ออปชั่นพิเศษอะไรบ้าง)
3. **Viewport Choke on Mobile:** บนจอมือถือ ผู้เล่นมองเห็นสล็อตในกระเป๋าได้เพียง 6 ถึง 8 ช่องต่อหน้าจอ การเลื่อนหาของในกระเป๋า 100 ช่องสร้างความเหนื่อยล้าให้กับผู้เล่นสูงมาก

---

### 3.2 สี่มาตรการหลักในการยกระดับ UX

```
+--------------------------------------------------------------------------+
|                      1. NOTABLE SHOWCASE SHELF                           |
|  [ Recent / Top Drops ]: (★ Naga Scale Rod) (★ Giant Golden Carp)        |
+--------------------------------------------------------------------------+
|  Tabs: [All] [Fish] [Rods] [Lines]            Sort: [Newest v]           |
+--------------------------------------------------------------------------+
|  [Slot 1]       [Slot 2]       [Slot 3]       [Slot 4]                   |
|  Normal Fish    Normal Bait    ★ GOD ROLL     ▲ UPGRADE                  |
|                                Naga Rod       Coral Rod                  |
|  [Slot 5]       [Slot 6]       [Slot 7]       [Slot 8]                   |
+--------------------------------------------------------------------------+
|                      AUTO-SCROLL & JUMP-TO-NEW                           |
+--------------------------------------------------------------------------+
```

#### มาตรการที่ 1: Showcase แถบสรุปไอเทมเด่นบนหัวเมนู (Noteworthy Quick Shelf)
- ติดตั้งแถบย่อส่วน "Recent Highlights" หรือ "Best Drops" ไว้เหนือ Grid ในหน้ากระเป๋าหรือหน้าผลลัพธ์
- แสดงเฉพาะไอเทมที่เข้าเกณฑ์ความเด่น:
  - Rarity ตั้งแต่ Epic ขึ้นไป
  - มี Mutation หรือ Modifier ระดับ Tier สูง
  - อุปกรณ์ที่เป็น Stat Upgrade เมื่อเทียบกับของที่ใส่อยู่
- เมื่อผู้เล่นแตะที่ไอคอนในแถบนี้ หน้าจอจะทำการ **Auto-scroll** ลงไปที่สล็อตนั้นใน Grid และเปิดการ์ด `ItemDetail` ให้อัตโนมัติ

#### มาตรการที่ 2: เพิ่ม Visual Cues ชัดเจนบนตัวสล็อต (In-Slot Telegraphing)
- **Upgrade Indicator:** แสดงไอคอนสามเหลี่ยมเขียวเล็กๆ ที่มุมสล็อต หากไอเทมชิ้นนั้นเพิ่มพลังให้ตัวละครได้มากกว่าชิ้นปัจจุบัน
- **God-Roll / Star Badges:** สล็อตที่มี Modifier สูงสุด แสดงป้าย Mini Badge สีทอง
- **Mutation Pip:** แสดงสัญลักษณ์ Mutation ชัดเจน พร้อมสีกรอบตามชนิด Mutation
- **Pulsing New Glow:** ไอเทมใหม่เอี่ยมที่ยังไม่เคยกดดู ให้มีเอฟเฟกต์เฟดนุ่มนวลรอบขอบสล็อต ดึงดูดสายตาทันทีที่เปิดหน้าต่าง

#### มาตรการที่ 3: ระบบจัดเรียงอัจฉริยะ (Smart Sorting & Auto-Scroll)
- ปรับ Sort เริ่มต้นให้มีตัวเลือก **"Newest First" (ของใหม่ล่าสุดขึ้นก่อน)** หรือ **"Notability / Rarity"** เป็นตัวเลือกอันดับต้นๆ
- เมื่อผู้เล่นเปิดกระเป๋าจากการแจ้งเตือนได้รับไอเทม (เช่น กดปุ่ม "ดูในกระเป๋า" จากหน้าตกปลาเสร็จ) ระบบจะสั่ง `VirtualGrid:ScrollToIndex()` ไปยังไอเทมนั้นทันที

#### มาตรการที่ 4: การปรับตัวของ ItemDetail ตามขนาดหน้าจอ (Adaptive Details)
- บนหน้าจอความกว้าง >= 1024px: คงรูปแบบการ์ดลอยด้านข้างสล็อต (`Side-by-side`)
- บนหน้าจอความกว้าง < 1024px หรือจอมือถือแนวตั้ง:
  - สลับเป็นการแสดงผลแบบ **Bottom Sheet** หรือ **Modal กลางจอ**
  - แสดงค่าเปรียบเทียบ Stat กับของที่ใส่อยู่ปัจจุบันทันทีในตัวการ์ด (Before vs After) เพื่อให้ตัดสินใจได้ในหน้าเดียว
  - ปุ่ม Action (Equip / Sell / Enhance) อยู่ในตำแหน่งที่นิ้วโป้งแตะถึงง่าย

## 6. ขั้นตอนการดำเนินการ (Step-by-Step Implementation Roadmap)

### เฟส 1: ขยายข้อมูล Notability บน ItemSlots
- [x] อัปเดต `src/client/UI/ItemSlots.luau` ให้คำนวณและเพิ่มป้ายสถานะ (ทำแล้ว: ป้าย UP, TOP, ขอบเรืองแสง Legendary ขึ้นไป, ขอบกระพริบสำหรับของใหม่):
  - ตรวจสอบ Stat เปรียบเทียบกับ Profile เพื่อติดป้าย `Upgrade`

## 7. เกณฑ์การตรวจรับงาน (Quality Gates)

1. **Item Notability:** ผู้เล่นเปิดกระเป๋าแล้วสามารถมองเห็นไอเทมที่มีค่า/ไอเทมใหม่ได้ทันทีโดยไม่ต้องเลื่อนหา
2. **No Clipping:** ไม่มีข้อความ, สล็อต, หรือปุ่มใดๆ ถูกตัดขาดหรือล้นออกนอกหน้าจอในทุกขนาดโปรไฟล์
3. **Always Accessible Actions:** ปุ่มปิด (X), ปุ่มย้อนกลับ, และปุ่มคำสั่งหลัก (ซื้อ/ขาย/ยืนยัน) ต้องอยู่ในพื้นที่ Safe Area และกดได้ 100%
4. **Strict Rules Compliance:**
   - ห้ามมีสัญลักษณ์ emoji, "✓", หรือ "•" ในโค้ดและ UI
   - ค่าตัวเลขเงิน Pearls ต้องเป็นจำนวนเต็มเสมอ
   - Luau Typecheck ต้องผ่านแบบ `0 error(s)` เสมอ

## 8. ปรับแผน (2026-11-23): ปัญหาใหม่ที่เจอ และงานที่เพิ่ม

### 8.1 ปัญหาที่ผู้ใช้เจอจากการเล่นบนมือถือ
1. **หน้าต่างเปิดครั้งแรกใหญ่เกินจอแล้วค่อยหดพอดี:** ครั้งแรกที่เปิด หน้าต่างยังไม่มีเลย์เอาต์ ทำให้ `FitToScreen` วัดขนาดไม่ได้ จึงเด้งที่ขนาดเต็มก่อนแล้วค่อยย่อ. แก้ที่ `New.FitToScreen`: ซ่อนที่ scale เล็กจนวัดได้ แล้วค่อย pop ขึ้นถึงขนาดที่พอดี (ทำแล้ว).
2. **Daily Login ไม่ responsive:** หน้าต่างล็อก 680x480 ไม่มี `FitToScreen`, ชิปหัวข้อทับชื่อ, ปุ่มปิด 36px เล็กเกินสำหรับนิ้ว. แก้เป็นเลย์เอาต์ 3 แบบ (กว้าง, มือถือแนวนอนเตี้ย, มือถือแนวตั้ง).
3. **ขอบ (stroke) ปุ่ม Depth ไม่ตรงกับปุ่มกลมอื่นบน HUD:** ปรับให้ใช้ค่า Plate เดียวกับ AUTO, SELL (Border, หนา 5, โปร่ง 0.9).
4. **ไอเทมเด่นหายใน Scroller:** คนได้ของดีแต่ไม่รู้ว่าน่าสนใจ ต้องเลื่อนหาเอง (ดูข้อ 8.2).

### 8.2 จุดที่ผู้เล่น "ได้ไอเทม" ทั้งหมด และสิ่งที่ต้องทำให้เห็นความเด่น
| แหล่งที่ได้ | ตอนนี้ | ต้องทำ |
| --- | --- | --- |
| ตกปลา (CatchResult card) | การ์ดผลลัพธ์ + จุดแดงที่ไอคอนกระเป๋า | ปลาที่เด่น (Epic+, Mutation) ไปอยู่แถบ Highlights ในกระเป๋า |
| คันเบ็ดดรอปจากตกปลา, หีบ | ข้อความแจ้งเตือน | แถบ Highlights + ป้าย TOP และ UP บนสล็อต |
| ซื้อที่ร้าน, ผลหลอม Fusion | อยู่ท้ายรายการ | Sort เริ่มต้น Newest + ปุ่ม NEW n |
| รางวัล Daily Login, Offline Reward | แสดงในหน้าต่างของมันเอง | ไม่เกี่ยวกับกระเป๋า (เหรียญ/เจม) ไม่ต้องทำเพิ่ม |
