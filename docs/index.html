2. ผังความเชื่อมโยงของระบบ (System Interconnection Map)

แผนผังแสดงทิศทางการไหลของทรัพยากรและความสัมพันธ์ระหว่างระบบต่างๆ ในเกมว่าแต่ละระบบเกื้อหนุนกันอย่างไร

1. การตกปลา (Fishing) Action Source
ระบบมินิเกมดึงปลา และการปล่อยตกออโต้ เป็นต้นน้ำของทรัพยากรทั้งหมดในเกม
ตกมือ (Manual) ขาย 1.5x - 2.25x
ตกออโต้ (Auto) รอบละ 14s (50% Gem)
OUTPUT -> ได้รับตัวปลา, ค่า EXP, หีบสมบัติ
2. การแปรรูปทรัพยากร Decision Point
ผู้เล่นเลือกว่าจะนำปลาไปทำอะไร เพื่อสร้างสกุลเงินที่ต้องการ
ขายที่ Merchant รับเงิน Coins
เลี้ยงใน Aquarium ผลิตไข่มุก Pearls/s
อัปเลเวล / Fishdex รับอัญมณี Gems
OUTPUT -> Coins / Pearls / Gems
3. การลงทุนพัฒนา Progression Sinks
นำสกุลเงินไปเพิ่มขีดความสามารถของตัวละครในแกนต่างๆ
Coins เบ็ด, สาย, ตีบวก +1..+10
Pearls Mastery ถาวร 7 สาย
Gems สุ่ม Aura Altar (5 Gems)
OUTPUT -> สเตตัสตัวละครสูงขึ้นอย่างก้าวกระโดด
4. การจุติ Rebirth Ascension
รีเซ็ตเงินและเลเวลเพื่อปลดล็อกตัวคูณและฉายาระดับตำนาน
เงื่อนไขเริ่ม Level 50 (+10/Tier)
ตัวคูณถาวร +0.25x Sell & Pearl
EFFECT -> ย้อนกลับไปเริ่มตกใหม่ด้วยตัวคูณมหาศาล
5. Stat Pipeline Single Source
ระบบคำนวณสเตตัสจุดเดียว (Single Pipeline) ควบคุมโดย Server
ฟังก์ชันกลาง Stats.Compute
รวมโบนัสจาก Rods/Lines/Bait/Aura/Pass
EFFECT -> ส่งผลกระทบทุกการเหวี่ยงเบ็ด
6. ระบบสนับสนุน (Store) Monetization
โครงสร้าง F2P Friendly ไม่ขายเงิน Coins ตรงๆ แต่ช่วยอำนวยความสะดวก
VIP (149 R$) +8h Offline, +15% Luck
Auto Pro (249 R$) -25% Wait, ขาย 1.25x
EFFECT -> เร่งสปีดแต่ไม่ข้าม Content Gap

4. กลไกการตกปลา (Fishing Mechanics: Manual vs Auto)

การเปรียบเทียบเชิงลึกระหว่างระบบเล่นเอง (Manual Minigame) และระบบปล่อยจออัตโนมัติ (Auto-Fishing)

คุณสมบัติ การตกมือ (Manual Fishing) การตกออโต้ (Auto Fishing) ผลต่างทางสมดุล
ตัวคูณราคาขายปลา 1.5x พื้นฐาน 1.0x (1.25x มี Auto Pro) ตกมือได้เงินมากกว่าขั้นต่ำ 50%
โบนัส Perfect Catch +0.25x ตัวคูณเพิ่ม ไม่มีโบนัสนี้ รางวัลสำหรับความแม่นยำของผู้เล่น
Hot Streak Bonus +0.05x สะสมได้ถึง +0.5x ไม่มีผล และไม่ทำให้หลุด สายเล่นมือต่อเนื่องทำยอดขายได้ถึง 2.25x
ความเร็วรอบการตก เฉลี่ย 4 - 8 วินาทีต่อรอบ รอบละ 14.0 วินาที (ลดได้ด้วย AutoSpeed) ตกมือเหวี่ยงรอบได้ไวกว่าอย่างมีนัยสำคัญ
อัตราดรอป Gems & กล่อง 100% เต็มจำนวน 50% (อัตราลดลงครึ่งหนึ่ง) จำกัดการฟาร์มอัญมณีของสายบอท AFK
ฟิสิกส์และตัวแปรมินิเกมเย่อเบ็ด (Reel Physics Dashboard)
หลอดเริ่มต้น (Start Progress)
25% StartProgress = 0.25
ผู้เล่นเริ่มเย่อที่ 1/4 ของหลอด ไม่เริ่มจาก 0% เพื่อลดความกดดัน
ความเร็วสะสมหลอด (Gain Rate)
+0.32 /s x ReelPower
ความเร็วหลอดเพิ่มเมื่อปลาอยู่ภายใน Catch Bar คูณด้วยพลังดึงของเบ็ด
ความเร็วหลอดลดลง (Loss Rate)
-0.22 /s x (1 - Resilience)
ความเร็วหลอดตกเมื่อปลาหลุดจากบาร์ ลดลงได้ด้วยค่าความเหนียวสาย
แรงยกบาร์ vs แรงถ่วงจม (Lift / Gravity)
3.6 vs 2.2 Lift / Fall Ratio
กดคลิกค้างเพื่อยกบาร์ (3.6) และปล่อยคลิกเพื่อให้บาร์จมลง (2.2)
ช่วงผ่อนปรนตอนเริ่ม (Start Grace)
0.6 วินาที Grace Period
บาร์จะเปิดตรงตัวปลาพอดีใน 0.6 วิแรก และปลาจะอยู่นิ่งเพื่อให้ตั้งตัวทัน
สเกลความยากของปลา (Difficulty Scale)
+18% / Tier Speed Factor 0.18
ปลาที่มี Difficulty สูงจะว่ายเร็วขึ้นตามสัดส่วนความยาก

5. ระดับความลึกของน้ำ 5 โซน (Depth Zones & Slider)

ระบบระดับความลึกเป็นเอกลักษณ์สำคัญ ผู้เล่นสามารถหมุน Slider บน HUD เพื่อระบุความลึกเป้าหมายได้ โดยสายเบ็ดต้องมีค่า MaxDepth รองรับ

โซนความลึก ช่วงความลึก (เมตร) สายเบ็ดขั้นต่ำที่รองรับ ลักษณะของสิ่งมีชีวิตและของรางวัล
1. Shallow Water 0 - 50m Cotton Line (30m) / Hemp Line (80m) ปลาทั่วไป, ปลาตัวเล็ก, หอยมุก (เหมาะสำหรับผู้เล่นเริ่มต้น)
2. Mid Water 51 - 200m Hemp Line (80m) / Nylon Line (150m) ปลาขนาดกลาง, ปลานักล่า, ปลากระเบน
3. Deep Sea 201 - 800m Spider-Silk Line (300m) / Abyss Line (600m) ปลาเรืองแสงธรรมชาติ, หมึกยักษ์, สปีชีส์โบราณ
4. Abyssal Trench 801 - 2,000m Star Line (1,000m) สัตว์ประหลาดน้ำลึก, ปลาปีศาจ, กล่องสมบัติโบราณ
5. Void 2,001m+ สายเบ็ดระดับพิเศษในอนาคต มังกรทะเล, บอสแห่งสายน้ำ, สัตว์ในตำนานระดับ Mythic

12. ไอเดียใหม่จากการประชุม (Roadmap from Meeting 21/11/2026)

รวบรวม 6 ฟีเจอร์ใหม่ที่ทีมงานได้ร่วมกันหารือ เพื่อเตรียมนำไปวางแผนลงชีตพัฒนาต่อไป

1. ระบบเรือ & การสำรวจเกาะ
NEW SYSTEM
ขับเรือออกสู่ทะเลลึกและเกาะต่างๆ โดยระดับน้ำจะค่อยๆ ลาดลึก (น้ำตื้น -> 200m -> 1,000m+) บังคับให้ผู้เล่นต้องอัปเกรดเรือควบคู่กับสายเบ็ด เพื่อป้องกันไม่ให้นั่งตกอยู่แค่ริมฝั่ง
เชื่อมโยงระบบ: DepthZones + WorldMap
2. เหยื่อพิเศษถาวร & Stash Rebirth
MONETIZATION
โมเดลแบบ Blox Fruits: เหยื่อพิเศษสุ่มเกิดตามเกาะ หายากแต่ใช้ได้ไม่จำกัด เมื่อ Rebirth จะหายไป เว้นแต่ซื้อด้วย Robux หรือซื้อ Permanent Stash ฝากของไว้ข้ามรอบ Rebirth
เชื่อมโยงระบบ: Rebirth + Baits
3. สภาพอากาศ & ปลาธาตุ
DYNAMIC EVENT
พายุ/ฟ้าผ่า ทำให้เกิดปลาเฉพาะช่วงเวลา เช่น ปลาสายฟ้า หรือทำให้ปลาน้ำลึกลอยขึ้นมา โดยปลาธาตุ (ปลาไฟ) นำโมเดลเดิมมาใส่เอฟเฟกต์ไฟลุกเพื่อประหยัดต้นทุน 3D
เชื่อมโยงระบบ: Fish + WeatherService
4. สมบัติ Relic & สุ่ม Mod คันเบ็ด
ECONOMY SINK
โมเดล PoE / Sol's RNG: เพิ่มไอเทม Relic สุ่มออฟชั่น และการซื้อคันเบ็ดจะสุ่ม Mod ติดตัว พร้อมระบบย่อยคันเบ็ดซ้ำ (Rod Fusion) เพื่อดึงไอเทมและ Coins ออกจากระบบ
เชื่อมโยงระบบ: Equipment + Enhance
5. Rework กระเป๋า & ปรับราคา Pass
REWORK
ปรับกระเป๋าให้นับ 1 ช่อง = 1 ตัวปลาตรงๆ ไม่มีการ Stack ซ้อน เพื่อให้การอัปเกรดกระเป๋ามีความสำคัญยิ่งขึ้น และเสนอปรับราคา Infinite Bag เป็นระดับพรีเมียม (1,000 - 1,499 R$)
เชื่อมโยงระบบ: Inventory + Products
6. 5 ปุ่มลอยหน้าจอ & จุดแดงเตือน
UI / UX
ดึง 5 เมนูหลักออกมาด้านนอก (Quest, Character, Bag, Aquarium, Rebirth) พร้อมระบบจุดแดงแจ้งเตือน (Red Dot) เมื่อมีของใหม่ โดยตัดระบบ 3D โฮโลแกรมหน้าตัวละครทิ้ง
เชื่อมโยงระบบ: MenuManager + HUD
