# Aura Fishing — 3D Model Turnaround Sheet Prompts

This document provides ready-to-use prompts for generating 4-angle model reference sheets (Front, Back, Side, and Isometric/3/4 Angle) for 3D asset modeling.

Style Target: **Stylized Low-Poly / Cozy Lake Fantasy RPG (Roblox compatible)**

---

## 1. Prompt Generation Formula

For each asset, apply the following prompt structure in your AI image generator (Midjourney v6, Flux, DALL-E 3, Stable Diffusion):

```
[Subject Description], character model turnaround sheet, 4 distinct orthographic and perspective views: front view, back view, side profile view, and 3/4 isometric angle view, arranged horizontally in a row, stylized 3D game asset, cozy lake fantasy art style, clean clear silhouette, smooth hand-painted gradient texture, low-poly friendly, studio soft neutral lighting, solid clean off-white background, no shadows on background, production ready model sheet, high resolution
```

### Universal Negative Prompt
```
photorealistic, hyperrealistic, noisy, messy lines, complex detailed background, outdoor scenery, text, labels, watermark, logo, signature, blurry, cropped limbs, inconsistent design between angles, perspective distortion
```
