# Storm Current - Aura VFX Specification

> **Rarity:** Rare  
> **Chance:** 1 in 400 (Order: 7)  
> **Base Stats:** +0.25 Luck, +0.08 Bite Speed  
> **Theme Colors:** Raindrop Blue `#96DCFF` (`rgb(150, 220, 255)`) and Spark Gold `#FFDC5A` (`rgb(255, 220, 90)`)  

---

## 1. แนวคิดการออกแบบและคุมธีม (Design & Cozy Theme Guardrails)

- **บรรยากาศ (Atmosphere):** บรรยากาศช่วงก่อนฝนแรกจะตกบนทะเลสาบ ผิวน้ำเริ่มหมุนวนเป็นเกลียวกระแสน้ำสดชื่น มีละอองน้ำหมุนวนพร้อมประกายไฟฟ้าสถิตสีทองเส้นบางๆ ปรากฏขึ้นในละอองฝน
- **คุมความเรียบง่าย (No Over-the-Top):**
  - ไม่ใช่พายุเฮอริเคนถล่ม หรือสายฟ้าฟาดระเบิดหน้าจอ
  - เป็นกระแสน้ำวนขนาดกะทัดรัดที่เท้า (Whirlpool Ring) สเกลพอเหมาะ
  - ประกายไฟฟ้าสีทองเป็นเพียงเส้นบางๆ (Micro Static Sparks) ในละอองน้ำ
  - ความเร็วของการหมุนวนให้ความรู้สึกกระฉับกระเฉง ช่วยเสริมสถิติ Bite Speed ของการตกปลา

## 3. ลำดับขั้นออร่า (Tier Progression)

- **Tier 1 (Base Ambient):** มีวงน้ำวนหมุนที่พื้น และละอองน้ำหมุนวนขึ้นรอบตัวเบาๆ
- **Tier 2 (Enriched Current):** แสงไฟสีฟ้าส่องสว่างขึ้น พร้อมประกายไฟฟ้าสถิตสีทองขนาดจิ๋วกะพริบในละอองน้ำ
- **Tier 3 (Signature Torrent):** เพิ่มกระแสน้ำวนสายฟ้าหมุนวนรอบเอว เสริมภาพลักษณ์นักตกปลาผู้ท้าทายสายฝน
